# ultrawhale-bench — Dogfood Inference Benchmark Harness

Standalone Rust CLI for measuring inference throughput (tokens/sec), memory overhead, and BitNet b1.58 accuracy on **Ultrawhale Dogfood fine-tuning datasets**.

---

## ⚡ Quick Start

```bash
cargo build --release
cargo run --release
```
